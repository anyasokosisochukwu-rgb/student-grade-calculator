## 📖 Description
The **Student Grade Calculator** is a web application designed to help calculate and manage student academic grades. Users can input a student's name and assessment scores. The app automatically computes the **Total Score**, **Average Score**, assigns a **Letter Grade**, and determines **Pass/Fail status**. All student records are saved automatically in the browser and remain even after closing or refreshing the page.

---

## ✨ Features
- ✅ Input student name
- ✅ Enter 3 or more assessment scores
- ✅ Calculate **Total Score**
- ✅ Calculate **Average Score**
- ✅ Assign **Letter Grade** (A – F)
- ✅ Show **Pass / Fail** status
- ✅ Display all student records
- ✅ Delete individual records
- ✅ Auto-save records (Local Storage)
- ✅ Input validation (prevent empty name & invalid scores)
- ✅ No installation required — runs in any web browser

## 📊 Grading System
The app uses the following grading scale to assign letter grades and determine pass status:

| Average Score | Letter Grade | Status |
|:---:|:---:|:---:|
| 90 – 100 | **A** | ✅ Pass |
| 80 – 89 | **B** | ✅ Pass |
| 70 – 79 | **C** | ✅ Pass |
| 60 – 69 | **D** | ✅ Pass |
| 50 – 59 | **E** | ✅ Pass |
| 0 – 49 | **F** | ❌ Fail |

> **✅ Passing Condition:** Average score of **50 or above** = Pass
> **❌ Failing Condition:** Average score **below 50** = Fail

3. Click or Tap **"Calculate & Save"** button
4. ✅ App instantly shows:

   - Average Score
   - Letter Grade

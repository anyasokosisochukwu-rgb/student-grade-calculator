# Student Grade Calculator

## 📝 Description
This application calculates student grades from assessment scores. It computes total score, average score, assigns letter grade (A–F), and shows Pass/Fail status. All records save automatically to Local Storage.

## ✨ Features
- Enter student name and 3 or more scores
- Calculate total score and average score
- Assign letter grade (A–F)
- Show Pass or Fail status
- Save records automatically
- Delete records
- Input validation

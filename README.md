# Student Grade Calculator
Calculate academic grades from assessment scores.

## Features
- Enter student name + 3+ scores
- Calculates total, average, letter grade (A–F)
- Shows Pass/Fail status
- Saves all records automatically
- Delete records anytime

## How to Run
1. Download all files
2. Open index.html in any browser
3. Enter details → click Calculate & Save

## Built With
HTML, CSS, JavaScript
